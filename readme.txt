== Description ==

**Dropify PRO** permite la integración automática de productos desde Dropi Pro a WooCommerce, facilitando la gestión y sincronización de productos en tu tienda en línea.

Dropify PRO es un plugin que permite a los usuarios mostrar e importar productos desde Dropi Pro a WooCommerce. Este plugin facilita la integración de productos en tu tienda WooCommerce de forma automática.

== Installation ==

1. Sube la carpeta del plugin `wc-dropi-pro-integration` al directorio `/wp-content/plugins/` o instala el plugin directamente a través de la pantalla de plugins de WordPress.
2. Activa el plugin a través de la pantalla de 'Plugins' en WordPress.
3. Asegúrate de que WooCommerce esté instalado y activado, ya que este plugin depende de WooCommerce.
4. Configura el plugin desde la sección "Dropify PRO" en el menú de WooCommerce.

== Frequently Asked Questions (FAQ) ==

= ¿Cómo configuro Dropify PRO después de la instalación? =
Ve a la sección "Dropify PRO" en el menú de WooCommerce para configurar el plugin y comenzar a importar productos.

= ¿Qué pasa si desinstalo el plugin? =
Si desinstalas el plugin, la configuración y los datos importados no se eliminarán, pero dejarás de tener acceso a las funciones de integración con Dropi Pro.
